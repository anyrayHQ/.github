# Support

Thanks for using [Anyray](https://docs.anyray.ai). Here's how to get help.

## 📚 Start with the docs

Most questions are answered at **[docs.anyray.ai](https://docs.anyray.ai)**:

- [What is Anyray?](https://docs.anyray.ai/) — the mental model
- [Org-admin guide](https://docs.anyray.ai/get-started/overview) — install, configure, operate
- [Developer guide](https://docs.anyray.ai/developers/overview) — connecting tools and SDKs
- [Connect your tools](https://docs.anyray.ai/developers/connect) — `npx anyray-connect`
- [FAQ](https://docs.anyray.ai/developers/faq)

## 💬 Questions & discussion

- **How-to / "is this possible" / configuration questions** →
  [GitHub Discussions](https://github.com/anyrayHQ/monorepo/discussions).
- **Search first** — your question may already be answered in an existing issue or discussion.

## 🐞 Bugs & feature requests

Open an issue in the relevant repository (usually
[`anyrayHQ/monorepo`](https://github.com/anyrayHQ/monorepo/issues)) using the issue forms. For a
bug, include what you expected, what happened, and the smallest reproduction.

> **Never include** prompt or response content, provider API keys, `ANYRAY_*` secrets, content
> keys, or admin tokens in an issue or discussion.

## 🔒 Security issues

Do **not** use the issue tracker. Follow the [Security Policy](./SECURITY.md) and report
privately to **[support@anyray.ai](mailto:support@anyray.ai)**.

## 📨 Commercial & everything else

For commercial inquiries, the [Anyray Portal](https://docs.anyray.ai/pricing/anyray-portal)
billing tier, or anything not covered above, email **[support@anyray.ai](mailto:support@anyray.ai)**.
