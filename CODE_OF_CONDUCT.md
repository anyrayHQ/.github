# Code of Conduct

[Anyray](https://github.com/anyrayHQ) has adopted the **[Contributor Covenant](https://www.contributor-covenant.org), version 2.1**, as the code of conduct for every Anyray repository, issue tracker, discussion, and other community space.

The full text is canonical and maintained upstream:

- **Read it:** <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

## The short version

We are committed to a welcoming, harassment-free experience for everyone. Be respectful, assume good faith, and accept constructive feedback gracefully. Project maintainers are responsible for clarifying and enforcing these standards and may remove, edit, or reject contributions and comments that don't align with this Code of Conduct.

## Scope

This Code of Conduct applies within all Anyray community spaces, and also when an individual is officially representing the project in public spaces.

## Reporting

Report abusive, harassing, or otherwise unacceptable behavior to the maintainers at **[support@anyray.ai](mailto:support@anyray.ai)** with the subject line `CONDUCT:`.

All reports will be reviewed and investigated promptly and fairly, and the privacy and security of the reporter will be respected.

> ⚠️ This channel is for **conduct** reports only. Security vulnerabilities follow the [Security Policy](./SECURITY.md), and bugs or feature requests go through the [issue forms](./.github/ISSUE_TEMPLATE).
